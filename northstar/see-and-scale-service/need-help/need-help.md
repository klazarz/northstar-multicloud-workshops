# Need Help?

## Introduction

Use these checks when you cannot access the database, metrics, or resource settings. Contact your facilitator or environment administrator for environment-specific help.

### Prerequisites

* Your assigned resource details and approved support contact.

## Task 1: Check access and data

1. If Database Actions does not open, check the approved client, network route, URL and user web access with your administrator. Do not share passwords or wallet files.
2. If `NS_INVENTORY` is missing, confirm that you are connected to the correct database and dedicated workshop user. Use the sample setup only in a confirmed clean schema. If the table already exists but its contents are uncertain, ask for help; do not drop or overwrite it.
3. If Azure Monitor shows no data, check the selected database scope, metric, time range, permissions and possible publication delay. Missing data is not a zero value.

## Task 2: Check an allocation operation

1. If the Manage control is unavailable, confirm your role and the provider's permissions. Use the decision-only path if changes are not permitted.
2. If a submitted change or restoration remains pending or fails, do not submit it repeatedly. Record the resource, original and requested values, status, time and owner; notify the facilitator or administrator so that any outstanding charges or restoration are managed.
