# Need Help?

## Introduction

If access, a method tab, resource creation or the SQL connection does not work, stop and ask the facilitator or environment owner. For Run on Multicloud, use the reservation's supplied support instructions.

### Objectives

* Describe the issue without exposing secrets or repeating uncertain operations.

### Prerequisites

* The lab and task number and a record of the current status.

## Task 1: Ask for help

Share the selected tab, lab and task, resource scope through an approved channel, non-sensitive error, and the latest request state. Do not share passwords, tokens, wallet files or private connection details in public messages. If creation is pending or uncertain, do not resubmit. The owner should determine its state and next action. Use the prepared fallback only after its identity and access are verified.
