# Introduction

## About this workshop

Northstar Outfitters is preparing a new inventory promotion. Maya, the operations lead, wants a database her team can use without managing the underlying servers. Alex, the cloud database specialist, needs to explain how to prepare the Azure network, choose the right creation method, and hand over a usable Oracle Autonomous AI Database Serverless resource on Azure.

Join Maya and Alex as you map responsibilities across Azure and OCI, inspect an approved delegated subnet, configure a 26ai database, and verify the outcome. You can follow the Azure Portal or Azure CLI path in the method tabs. OCI Console and OCI CLI tabs explain why those tools do not create this resource and point you to a supported Azure path. The story and inventory data are fictional.

**Estimated time:** 90 minutes after the environment is prepared. This workshop is a deeper creation-method companion to **Launch the Inventory Service**. It can also stand alone. No inventory data is assumed to appear automatically in a new database.

### Objectives

* Identify onboarding, permissions, network, quota and cost prerequisites for Oracle AI Database@Azure.
* Compare the supported creation methods and their cloud boundaries.
* Inspect or create an approved Azure VNet and delegated subnet using a supported method.
* Configure and, where permitted, submit an Autonomous AI Database Serverless 26ai resource using Azure Portal or Azure CLI.
* Verify database status, connect to an available database, and explain the result to Maya.

### Prerequisites

* Familiarity with cloud consoles and basic SQL; the Northstar QuickStart is helpful but not required.
* The prepared environment and access described in the appropriate Get Started lab, including an available 26ai fallback database and SQL user.
* For a new resource, an owner-approved configuration, permissions, quota, network, budget and unique names. Azure CLI users also need an approved shell and authenticated Azure CLI with the documented extension.
