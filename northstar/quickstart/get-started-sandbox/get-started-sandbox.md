# Get Started

## Introduction

Connect to the prepared workshop database and open a SQL worksheet. The database must be ready before you begin; provisioning is covered in a later workshop.

Estimated lab time: 10 minutes

### Objectives

* Open the SQL worksheet using your assigned workshop user.

### Prerequisites

* Oracle Autonomous AI Database Serverless on Azure running Oracle AI Database 26ai. Confirm the version with your environment owner before running the SQL.

* A dedicated database user with Database Actions access, permission to create a table, and sufficient storage quota.
* An approved network path to the database and its Database Actions URL.

## Task 1: Connect to your provided environment

1. Open the access instructions for your Run on Multicloud reservation. Locate the assigned database name, Database Actions URL, workshop username, and the approved way to obtain the password.
2. If the reservation instructions specify a remote desktop or another approved client, open it first and use its browser.
3. Open the assigned Database Actions URL, sign in as the workshop user, and select **SQL**. Keep the worksheet open for the next lab.

If the reservation does not provide these details or the URL is unreachable, contact your facilitator or the reservation support team. Do not share passwords, wallet files, or connection details in screenshots or workshop comments.

You may now **proceed to the next lab**.
