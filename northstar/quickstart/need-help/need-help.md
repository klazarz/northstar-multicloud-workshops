# Need Help?

## Introduction

Use these checks if you cannot connect or your results differ from the expected output.

### Prerequisites

* Your workshop access instructions and the name of your assigned database user.

## Task 1: Check your access

1. If the URL does not open, use the approved network or remote desktop described in your environment instructions. Ask your administrator or facilitator to verify the URL and access path.
2. If sign-in fails or SQL is unavailable, ask them to check the database user, credentials, account status, and Database Actions access.
3. Never share passwords, wallets, or connection details in screenshots or public messages.

## Task 2: Check the lab state

1. If the table name is already in use, request a clean workshop schema. Do not drop an existing table.
2. If the row count or results differ, confirm your workshop user and ask for help checking the data. Do not blindly reload or delete existing data.
3. For a provided reservation, contact the facilitator or the support contact in your reservation instructions. For your own environment, contact your database administrator.
