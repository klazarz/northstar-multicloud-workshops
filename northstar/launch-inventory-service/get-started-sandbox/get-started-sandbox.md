# Get Started

## Introduction

Use the access instructions supplied for your Run on Multicloud reservation to locate the workshop environment.

Estimated lab time: 10 minutes, after the environment is ready.

### Objectives

* Identify your assigned Azure resources and the prepared fallback.

### Prerequisites

* Oracle Autonomous AI Database Serverless on Azure running Oracle AI Database 26ai. Confirm the version with your environment owner before running the SQL.

* A Run on Multicloud reservation that provides this Azure database service, the appropriate Azure and OCI access, an approved virtual network and delegated subnet, and a client with private network access.
* Permission to create a database in the assigned scope, or a facilitator who can perform the creation for you.
* An available fallback database and a dedicated workshop schema with Database Actions access, CREATE TABLE privilege and storage quota.

## Task 1: Open your assigned environment

1. Open the reservation instructions and sign in to the supplied Azure environment. Record the assigned subscription, resource group, region, virtual network, delegated subnet and approved database settings.
2. Locate the approved client or remote desktop, the fallback database name, Database Actions URL and workshop credentials. Follow the reservation instructions for secure credential access.
3. Confirm who prepares the workshop user on a newly created database and who owns resource cleanup. If these details or permission to create are not supplied, contact the facilitator before continuing.

The availability and exact access flow of this sandbox must be confirmed by the workshop provider. Do not assume that a generic OCI sandbox includes an Azure subscription or this service.

You may now **proceed to the next lab**.
