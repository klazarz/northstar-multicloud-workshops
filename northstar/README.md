# Northstar multicloud workshops

Draft Oracle LiveLabs workshops for Oracle Autonomous AI Database Serverless on Azure, following the fictional Northstar Outfitters team.

* `northstar/quickstart` — an introductory inventory exercise.
* `northstar/launch-inventory-service` — provision and connect an inventory service.
* `northstar/see-and-scale-service` — observe the service and consider capacity.
* `northstar/recover-from-a-mistake` — investigate a mistake using a backup clone.
* `northstar/create-autonomous-database` — explore Azure creation methods and delegated networking.

Each workshop has separate `workshops/tenancy` and `workshops/sandbox` manifests and an accompanying facilitator guide. Workshop content is a draft: live pilots, environment availability, support details, accessibility, and independent quality assessment require validation before publication. See the facilitator guides for preparation and status.

The curriculum recommendation and research prompt are included in this folder. Local renderer assets under `northstar/assets` are retained because the workshop pages reference them.
